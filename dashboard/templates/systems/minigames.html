🎲 Weekly Spawn Settings
Enabled

Games spawn automatically with a probability that adapts daily to stay within your min/max weekly range — behind pace pushes the odds up, ahead of pace pushes them down. On the last day of the week, if the minimum still hasn't been hit, a game force-fires regardless of the roll. Enabled OFF only stops the automatic system — manual and test spawns keep working.

🎁 Global Default Reward Preset

When a new game is created without its own reward pool (and its category has no preset), it starts with this pool. Each winner rolls one reward independently (weighted). An empty preset is valid — games will just have no rewards.
